# Meeting Preparation and Follow-up

## Purpose
Help the user prepare for meetings and preserve useful follow-up context.

## Expected behavior
For a commitment identified as a meeting, the user can record and edit preparation information before it occurs and follow-up notes afterward. Notes can link to related contacts and tasks, and can be viewed from the meeting.

## Inputs / outputs
The user supplies preparation text, follow-up text, and optional contact/task links. The app stores and displays those notes with the meeting.

## User-visible behavior
Meeting details distinguish preparation from follow-up and show linked records and editable notes.

## Constraints
Notes remain local and user-entered; no automatic transcription or external meeting integration is required.

## Basic acceptance expectations
The user can save both before- and after-meeting notes, reopen them, edit them, and follow links to associated contacts and tasks.
