# Basic Reminders

## Purpose
Keep upcoming and overdue responsibilities visible without requiring external delivery systems.

## Expected behavior
The app creates or displays reminders for upcoming and overdue tasks and commitments. The user can acknowledge, snooze, or dismiss a reminder; snoozing requires a new local time/date.

## Inputs / outputs
The user supplies reminder timing and action choices. The app displays reminder state and updates the related responsibility as appropriate.

## User-visible behavior
Reminder status is visible in the dashboard and relevant detail views, with clear upcoming, overdue, acknowledged, snoozed, and dismissed states.

## Constraints
Reminders are in-app only. No email, browser push, or other external notification channel is required.

## Basic acceptance expectations
Upcoming and overdue reminders appear, and acknowledge/snooze/dismiss actions persist and visibly change state.
